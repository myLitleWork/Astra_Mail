# Как установить и запустить AstraMail

1. Распакуйте **весь ZIP-архив** AstraMail в отдельную папку, например в домашнем каталоге.
2. Откройте распакованную папку, затем папку **scripts**.
3. Откройте в этой папке терминал и выполните:

   ```bash
   bash ./install_astramail.sh
   ```

4. Дождитесь сообщения **«Готово»**.
5. Запустите **AstraMail** с ярлыка на рабочем столе или из меню приложений.

Устанавливайте от своего пользователя **без sudo**. Если программа уже запущена, закройте её перед установкой.

Если ярлык не появился, запустите из терминала:

```bash
"$HOME/.local/bin/AstraMail"
```

При первом запуске выберите свой настроенный почтовый профиль и задайте пароль почты и PIN. Если профилей нет, сначала подготовьте почтовые настройки по [инструкции первой настройки](AstraMail_Initial_Setup_Guide.html). Установщик не создаёт почтовый ящик.

Проверено на Astra Linux 1.6 x86_64. Установка на 1.8.6 отдельно не проверялась.

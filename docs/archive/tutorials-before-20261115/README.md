# Предыдущие руководства AstraMail

Исходные шесть файлов из пакета 3.3.3 сохранены здесь без изменения содержимого
15.11.2026. Они не входят в новую поставку. Актуальное руководство находится
в [tutorials/содержание.html](../../../tutorials/содержание.html).

Этот архив сохраняет пользовательский Word-оригинал и прежние MD/HTML,
включая старые пути меню и конкурирующий сценарий обновления. Он не является
актуальной инструкцией. Полное содержание и иллюстрации Word отдельно
не актуализировались; Word-файл не удалён.

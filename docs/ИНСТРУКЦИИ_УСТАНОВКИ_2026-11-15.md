## Результат

Основной установочный маршрут теперь один: распаковать весь ZIP, открыть
scripts, открыть там терминал, выполнить `bash ./install_astramail.sh`,
дождаться «Готово» и запустить с ярлыка. Существующая tutorials/Установка.md
сокращена под этот сценарий. В README исходников и README будущего пакета
она показана как основной вход; конкурирующие команды portable-запуска убраны
из основного README пакета.

Подробности прежней инструкции установки (обновление, сохранение данных,
откат, пути) сохранены в docs/УСТАНОВКА_И_ОБНОВЛЕНИЕ_ПОДРОБНО.md.
Документы не удалялись: пользователь запросил рекомендации об удалении.

## Проверки и ограничения

Команда сверена с реальным scripts/install_astramail.sh: он определяет пакет
от своего пути, работает без sudo, проверяет исходные checksum, исполняет
только локальную копию, создаёт команду и ярлыки. Требуется распакованный
полный пакет; отдельный скрипт без остальных файлов не подходит.

Проверены локальные ссылки изменённых MD с учётом будущего размещения README
пакета. Выполнен git diff --check. Новые runtime/installer/GUI-прогоны не нужны
для текстовой правки и не выполнялись; прежние результаты Release не выданы
за новую проверку. Код программы и установщик не менялись.

Версия не повышалась, новый Release/публикация/commit/push не выполнялись.
Уже опубликованный ZIP 3.3.2 и копия MY_FLASH сохраняют прежние руководства.
Изменения текста войдут в пакет при следующем каноническом выпуске.
Рабочие настройки/почта/пароли не читались.

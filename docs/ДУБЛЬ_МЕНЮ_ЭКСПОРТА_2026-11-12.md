## Причина

`src/menu/MenuCreator.cpp:126` безусловно создаёт команду экспорта всего
списка IMAP-папок. Затем цикл в `src/menu/MenuCreator.cpp:136` создаёт
отдельную команду для каждой папки из того же списка.

`src/menu/Commands/Mails/CmdExportUnreadToFolders.cpp:361` выбирает подпись
«Все папки» только при размере списка больше одного. Для одного элемента
используется «Папка INBOX». Поэтому при единственной доступной папке INBOX
общая и отдельная команды имеют одинаковые подписи, папку назначения,
режим и список исходных папок. Конструкторы сохраняют соответственно
`folders_(folders)` (строка 787) и `folders_{ std::move(folder) }` (строка 350);
`execute()` передаёт эти списки в один `runExport()` (строка 773).

Это избыточное построение меню. Корректный вариант: при одной папке оставить
одну команду; общий пункт добавлять, когда папок несколько. Случай пустого
списка следует проверять отдельно из-за предусмотренного офлайн-переноса.

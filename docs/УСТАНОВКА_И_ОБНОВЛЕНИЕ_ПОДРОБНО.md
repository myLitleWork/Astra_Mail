# Подробности установки, обновления и возврата AstraMail

Пакет предназначен для Astra Linux 1.6 x86_64. Перед обновлением завершите
программу. Устанавливайте от своего обычного пользователя, без sudo.

Распакуйте весь ZIP. В терминале папки пакета выполните:

```sh
bash ./scripts/install_astramail.sh
```

Можно открыть терминал в `scripts` и выполнить `bash ./install_astramail.sh`
или передать полный путь к скрипту: текущая папка не влияет на выбор пакета.
На флешке с noexec используйте именно `bash`, запускать бинарник с флешки
не требуется. Установщик проверяет контрольные суммы, копирует файлы на
локальный диск и только там проверяет запуск программы.

Комплект программы, библиотека, инструкции и образец CSV устанавливаются
в `~/.local/opt/AstraMail`. Команда запуска — `~/.local/bin/AstraMail`.
Ярлык появляется в меню приложений и в настроенном каталоге рабочего стола.
Если рабочий стол отключён, создаётся только запись меню. Ярлык открывает
терминал. Если команда `AstraMail` не найдена в PATH, запускайте её полным путём:

```sh
"$HOME/.local/bin/AstraMail"
```

Обычный запуск предложит настройку профиля и PIN. Установщик не создаёт
учётную запись, не импортирует контакты и не отправляет письма.

При повторной установке прежняя программа сохраняется в отдельном каталоге
`.AstraMail.install.*` рядом с новой. Точный путь выводится в терминале.
Файлы правил и настройки рядом с прежним бинарником переносятся; при переходе
со старого установщика учитываются файлы программы в `~/.local/bin`.
При ошибке замены восстанавливаются прежняя программа, команда и ярлыки.
Сообщение «Готово» появляется после успешной проверки установленной версии.

Почта, профили, секреты и очередь в `~/.astramail` и
`~/.local/share/AstraMail` общие для запусков пользователя. Перед обновлением
сохраните их отдельную копию при остановленной программе. Резервная копия
папки программы не заменяет резервную копию этих данных. Сохраните старую
версию до проверки всех нужных функций и периода стабильной работы.

Для ручного возврата завершите программу, сохраните новую папку отдельно,
скопируйте `previous-app` из указанного установщиком каталога на место
`~/.local/opt/AstraMail`. Сохранённые команда и ярлыки находятся в `previous`:
`launcher`, `menu`, `desktop`; верните их на пути, показанные при установке.
Если обновлялась старая установка с одним бинарником, вместо `previous-app`
будет сохранён прежний бинарник в `previous/launcher`. Учитывайте изменения
общих данных перед запуском старой версии.

# Монтирование MY_FLASH обычным пользователем

- Дата: 15.11.2026, Asia/Yekaterinburg UTC+05.
- Baseline: Release 3.3.2, HEAD a576ae3 + сохранённый dirty выпуска и предыдущих
  задач. Прочитаны оба указателя, правило учёта и отчёт обычного пользователя
  от 12.11.2026. Его ограничение USB-доступа проверено этой задачей.
- Метод: SSH, состояние активного сеанса/устройства, конфигурация разрешений,
  реальное mount/umount и синтетическая запись от UID 1001.
- Статус: завершено в проверенной области, повтор GUI-клика оставлен пользователю.

## Причина и исправление

У astramail-test активный локальный сеанс, но обычный mount не разрешал
подключение NTFS-раздела; отсутствовали запись user в fstab и доступ к самому
блочному устройству. Udisks из проверочного SSH-контекста также требовал
авторизацию. Права sudo/администратора для исправления пользователю не выдавались.

Добавлена единственная запись /etc/fstab по UUID 067AF3F97AF3E2FB, для
пользовательской точки /run/user/1001/media/by-uuid-067AF3F97AF3E2FB:
ntfs-3g, noauto,user,uid=1001,gid=1002,umask=0077,nosuid,nodev,noexec.
Предыдущий fstab сохранён как /etc/fstab.astramail-usb-20261115.bak.

Правило /etc/udev/rules.d/99-astramail-my-flash.rules выдаёт владельца
astramail-test и режим 0600 только съёмному разделу с этим UUID. Это включает
прямой доступ пользователя к соответствующему блочному разделу MY_FLASH;
на остальные диски правило не распространяется. Группа disk не выдавалась.

## Проверки

- Устройство опознано по метке MY_FLASH и UUID, removable=1; в этой сессии sdf1.
- Правило udev применено адресно; собственник устройства UID 1001.
- mount выполнен от astramail-test из его доступного HOME без повышения прав.
- Создан новый временный файл на USB, выполнены запись/fsync/чтение/сравнение
  синтетических байтов и удаление только этого файла — успешно.
- Тот же пользователь выполнил umount и повторный mount — успешно.
- Итоговые mount options: rw,nosuid,nodev,noexec,user_id=1001,group_id=1002.
- sudo -n true от обычного пользователя по-прежнему отказан; id показывает
  только собственную группу. Флешка оставлена смонтированной для ручного теста.

Промежуточный helper сообщил о нештатном закрытии NTFS в Windows и выполнил
своё штатное восстановление. Дополнительные repair/format не запускались.
Ещё одна проверочная попытка не прошла из-за недоступного текущего каталога
sg; повтор из HOME astramail-test успешен. Эти неудачные попытки не выдавались
за успешное пользовательское монтирование.

## Ограничения

Повторный GUI-клик Fly, извлечение/переподключение и reboot не проверены.
Точка в /run создаётся в пользовательском сеансе; её наличие после нового
входа следует проверить отдельно. Правило относится к конкретной MY_FLASH
и конкретному UID, а не ко всем пользователям или носителям.
Код/релиз/версия AstraMail не менялись, сборка и публикация не выполнялись.
Рабочая почта, секреты и содержимое чужих файлов USB не читались.

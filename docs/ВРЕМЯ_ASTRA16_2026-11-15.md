## Причина и исправление

До исправления системные часы показывали 14 ноября, RTC — 15 ноября.
Часовой пояс был Europe/Moscow. NTP формально включён, но ntp и
systemd-timesyncd не работали; последний имел невыполненное условие запуска
с drop-in disable-with-time-daemon.conf. Установлены ntp и ntpdate.

Выполнено по SSH:

```sh
sudo systemctl stop ntp
sudo ntpdate -u pool.ntp.org
sudo systemctl enable ntp
sudo systemctl start ntp
sudo timedatectl set-timezone Asia/Yekaterinburg
```

Разовая коррекция: +76389.028333 секунды. Конфигурация NTP-серверов,
SSH и ключи не редактировались. Пакеты не устанавливались.

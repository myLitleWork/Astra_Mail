Для Thunderbird показана матрица по формату данных, а не неподтверждённый
список «всех совместимых версий». Код читает abook.sqlite, history.sqlite
и abook-*.sqlite; SQL ждёт properties и структуру списков lists/list_cards.
MAB напрямую не читается. Отдельно указаны старые MAB, SQLite, неполный
импорт списков, пустой/отсутствующий профиль, несколько профилей, POP3 и
отсутствие гарантированной поддержки иных хранилищ адресов.

Исторический переход Thunderbird 78 на SQLite проверен по
[официальным release notes](https://www.thunderbird.net/en-US/thunderbird/78.0/releasenotes/).
Это не новая runtime-проверка каждой версии Thunderbird.

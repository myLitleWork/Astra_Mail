# Запуск и обновление AstraMail

Пакет предназначен для **Astra Linux 1.6 x86_64**. Распакуйте весь ZIP в
отдельную доступную для записи папку. В терминале этой папки выполните:

```sh
sh ./Verify-Package.sh
sh ./Run-AstraMail.sh
```

Проверка требует `sha256sum`. Вместе с программой поставляется libsodium;
системная glibc берётся из ОС. Запускающий скрипт подключает библиотеку из
`lib` и восстанавливает бит исполнения, который может потеряться при
переносе ZIP через Windows. Имя бинарника остаётся `AstraMail`.

Версия проверяется командой `sh ./Run-AstraMail.sh --version`; эта команда
не открывает профиль и не создаёт пользовательские настройки. `version.txt`,
manifest и контрольные суммы относятся к исходному пакету. После работы
рядом с программой могут появиться настройки, отсутствующие в manifest.

Образец CSV и порядок импорта описаны в [инструкции](Импорт_справочника.md).
Образец не импортируется автоматически. Почта, профили и секреты в релиз
не входят; обычная настройка аккаунта выполняется в интерфейсе программы.

Для обновления сначала завершите программу и сохраните полную копию прежней
папки. Обновляйте её отдельную копию: замените бинарник, `lib`, запускающий
скрипт, проверочные файлы и руководства, сохранив свои настройки. Проверьте
операции и поработайте с новой копией до удаления прежней.

Секреты и кэш профиля в `~/.astramail`, очередь и локальная почта в
`~/.local/share/AstraMail` общие для запусков одного пользователя. Копия
папки программы не копирует эти данные: перед обновлением отдельно
сохраните их при остановленной программе. При возврате учитывайте изменения
общих данных; не запускайте две копии одновременно против одного профиля.

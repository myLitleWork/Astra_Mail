В «Настройках» — аккаунт, адресная книга, правила и интервалы фона. Перед ручной правкой сохраните копию; после неё надёжнее перезапустить программу.

Почтовый аккаунт

Меню «Настройки → Почтовый аккаунт» позволяет выбрать профиль, посмотреть параметры, разблокировать аккаунт и открыть редактор. В ~/.astramail/profile_cache/mail_settings.conf используется key=value; # начинает комментарий.

ПоляНазначение
email, full_nameАдрес и имя отправителя.
user_nameЛогин IMAP/SMTP; локальный формат не задаёт разные логины.
imap_host, imap_portВходящий сервер и порт.
smtp_host, smtp_portИсходящий сервер и порт.
profile_id, profile_path, account_id, identity_idИдентификация снимка; смена параметров может потребовать отдельного секрета/PIN.
imap_ssl, smtp_sslСохранённые признаки профиля; они не включают TLS в текущем транспорте.

Пример структуры, не готовое подключение: замените вымышленные параметры согласованными с администратором.

profile_id=local_profile
profile_path=
account_id=local_account_1
identity_id=local_identity_1
email=sender@example.invalid
full_name=Учебный отправитель
user_name=sender@example.invalid
imap_host=imap.example.invalid
imap_port=143
imap_ssl=0
smtp_host=smtp.example.invalid
smtp_port=25
smtp_ssl=0

Пароли/PIN здесь не хранятся. Заглушки CHANGE_ME, imap.example.com и smtp.example.com не принимаются как готовый аккаунт. См. первый запуск и ограничения связи.

Три вида правил

«Настройки → Правила обработки писем». Файлы лежат рядом с бинарником, после установки — в ~/.local/opt/AstraMail.

ФайлФормат
subject_rules.confпапка | regex/wregex/default | шаблон. Для темы берётся первое совпадение; wregex — для кириллицы, UTF-8.
attachment_groups.confпапка : .расширения. Общую группу * ставьте последней.
outgoing_subject_rules.confтема : .расширения prefix:начало_имени. Для нескольких вложений могут объединяться темы.

Примеры для трёх разных файлов:

Служебные | regex | ^(re:|fw:)
Учебные | wregex | .*учеб.*
Прочее | default | *

Документы : .pdf .doc .docx
Прочее : *

ОТЧЁТ : .pdf prefix:report
ПИСЬМО : *

Не вставляйте все блоки в один файл. Общее правило — в конце. Для prefix: надёжнее латиница; не рассчитывайте на преобразование регистра кириллицы. Некорректное правило может быть пропущено: проверьте учебные темы/файлы.

Сохранение и применение

Редактор выбирается из EDITOR, затем nano, vi, less. Less предназначен для просмотра. Сохраните файл в UTF-8 и закройте редактор. Настройки аккаунта и книга подхватываются при следующем запуске; повторный выбор Thunderbird может заменить их импортом.

Правила читаются при соответствующих операциях; после правки перезапуск даёт единое состояние. Интервалы фона перечитываются фоновым модулем; сетевые интервалы — при запуске.

Сброс настроек

Отдельное меню содержит шесть действий: профиль, адресная книга, темы входящих, группы вложений, темы исходящих, интервалы фона. Каждое заменяет один файл значениями по умолчанию после подтверждения. Результат и отмена остаются до Enter.

Сброс профиля оставляет шаблон, который нужно заполнить; сброс книги заменяет ваши записи образцом. Это не возврат резервной копии и не сброс PIN. Сохраните нужные файлы заранее; после сброса аккаунта/контактов перезапустите и проверьте их.

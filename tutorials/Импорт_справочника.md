# Импорт справочника из CSV

Рядом с программой находится `contacts-import-example.csv`. Это образец с
тремя вымышленными контактами и адресами `example.invalid`; замените строки
своими данными перед рабочим импортом.

Формат: **UTF-8 без BOM**, разделитель **запятая**, окончания строк **LF**.
Сохраните первую строку без изменений:

```csv
Отображаемое имя,Псевдоним,Адрес электронной почты
```

Каждая следующая строка — один контакт. Email обязателен. Поле с запятой
заключайте в двойные кавычки, кавычку внутри поля удваивайте. Не используйте
переносы строк внутри полей. Выбирайте уникальные псевдонимы, например
`demo_office`: они служат ключами контактов. Пробелы в ключе превращаются
в подчёркивания; латинские буквы приводятся к нижнему регистру.

В программе откройте «Система» → «Импорт контактов из CSV (выбор папки/файла)»
→ «Рядом с exe» → нужный CSV. Для файла на рабочем столе или в домашнем
каталоге выберите соответствующую папку. После импорта проверьте показанное
число контактов и откройте просмотр локального справочника.

Импорт добавляет контакты и обновляет совпавшие ключи; списки рассылки
сохраняются. Это не замена всего справочника. Пустой псевдоним берётся из
отображаемого имени, а при отсутствии обоих — из части email до `@`.

При сохранении из табличного редактора явно выберите UTF-8, запятую и LF:
обычный экспорт «CSV» может использовать другую кодировку, точку с запятой
или CRLF. Программа не выполняет автоматическую конвертацию этих вариантов.

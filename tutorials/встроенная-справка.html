Эти шесть текстов совпадают со справками меню «Справка и туториалы». Их можно читать без запуска программы.

Практические шаги — в разделах настроек, контактов и связи.

Настройки профиля

Настройки аккаунта: ~/.astramail/profile_cache/mail_settings.conf
Формат: key=value; строки с # — комментарии.

Нужны email, user_name, imap_host, imap_port, smtp_host, smtp_port.
full_name — имя отправителя. Профиль и аккаунт имеют свои идентификаторы.
Не храните пароль почты или PIN в этом файле.
Значения CHANGE_ME и серверы-заглушки нужно заменить.
После ручной правки завершите программу и запустите её заново.

Ограничение текущего транспорта: TLS, STARTTLS и OAuth2 не реализованы.
Поля imap_ssl/smtp_ssl сохраняют параметры, но не включают шифрование.
Используйте согласованное с администратором защищённое сетевое окружение
и совместимые IMAP/SMTP-серверы; не отключайте защиту публичного сервиса.

Адресная книга

Адресная книга: ~/.astramail/profile_cache/contacts.conf

Контакт: C|key|email|displayName|nickName
Пример: C|demo_office|office@example.invalid|Учебный отдел|demo_office

Удобнее задавать уникальный псевдоним и так же называть папку на флешке.
Без псевдонима возможен поиск по отображаемому имени или части email до @.
Если найдены несколько подходящих контактов, получатель не выбирается.
Имя папки может быть полным email или списком email через запятую.
Список рассылки имеет приоритет перед отдельным контактом.

Список: L|имя_списка|email1,email2
Пример: L|demo_team|office@example.invalid,duty@example.invalid

CSV: Настройки → Адресная книга → Импорт контактов из CSV.
Импорт добавляет/обновляет контакты по ключу, сохраняя списки.
После ручной правки contacts.conf перезапустите программу.

Правила темы письма

# ─────────────────────────────────────────────────────────────
# Пояснения для пользователей
# ─────────────────────────────────────────────────────────────
#
# Этот файл содержит ПРАВИЛА распределения писем по папкам
# на основе ТЕМЫ письма (Subject).
#
# Формат строки:
#   ПАПКА | ТИП_СРАВНЕНИЯ | ШАБЛОН
#
# Пример:
#   Служебные | regex | ^(re:|fw:)
#
# ─────────────────────────────────────────────────────────────
# Что такое регулярные выражения (regex)
# ─────────────────────────────────────────────────────────────
#
# Регулярное выражение — это шаблон для поиска текста.
# Проще говоря: "как выглядит нужная строка".
#
# ─────────────────────────────────────────────────────────────
# Основные элементы regex
# ─────────────────────────────────────────────────────────────
#
# .   — любой один символ
# .*  — любой текст любой длины
# ^   — начало строки
# $   — конец строки
# |   — ИЛИ
# ()  — группировка
#
# Пример:
#   .*шт.*  → строка содержит "шт" где угодно
#   ^(re:|fw:) → начинается с re: или fw:
#
# ─────────────────────────────────────────────────────────────
# ВАЖНО ПРО РУССКИЕ БУКВЫ
# ─────────────────────────────────────────────────────────────
#
# Регулярные выражения с русскими буквами могут работать
# по-разному. Если правило не срабатывает:
#   - используйте тип wregex
#   - убедитесь, что файл сохранён в UTF-8
#
# ─────────────────────────────────────────────────────────────
# Проверка регулярных выражений
# ─────────────────────────────────────────────────────────────
#
# Рекомендуется проверять шаблоны на сайте:
#   https://regex101.com/
#
# ─────────────────────────────────────────────────────────────
# Порядок правил ВАЖЕН
# ─────────────────────────────────────────────────────────────
# Первое совпавшее правило применяется.
# Общее правило должно быть в конце.
#

Группы вложений

# ─────────────────────────────────────────────────────────────
# Пояснения для пользователей
# ─────────────────────────────────────────────────────────────
#
# Этот файл содержит ПРАВИЛА группировки вложений по папкам
# на основе РАСШИРЕНИЯ ФАЙЛА.
#
# Формат строки:
#   ПАПКА : РАСШИРЕНИЯ
#
# Пример:
#   Документы : .doc .docx .pdf
#
# ─────────────────────────────────────────────────────────────
# Как работают правила
# ─────────────────────────────────────────────────────────────
#
# Программа берёт расширение файла и ищет подходящее правило.
# Если расширение совпало — файл попадает в указанную папку.
#
# Пример:
#   report.pdf  → папка "Документы"
#   image.jpg   → папка "Изображения"
#
# ─────────────────────────────────────────────────────────────
# Как задаются расширения
# ─────────────────────────────────────────────────────────────
#
# Расширения перечисляются через пробел.
# Точка ОБЯЗАТЕЛЬНА.
#
# Пример:
#   .txt .log .csv
#
# ─────────────────────────────────────────────────────────────
# Специальное правило "*"
# ─────────────────────────────────────────────────────────────
#
# Символ * означает "всё остальное".
# Это правило применяется, если ни одно другое не подошло.
#
# Пример:
#   Прочее : *
#
# ─────────────────────────────────────────────────────────────
# Порядок правил ВАЖЕН
# ─────────────────────────────────────────────────────────────
#
# Правила проверяются СВЕРХУ ВНИЗ.
# Первое совпавшее правило — применяется.
#
# Поэтому правило "Прочее : *"
# ДОЛЖНО БЫТЬ В САМОМ КОНЦЕ.
#

Правила темы исходящего

# ─────────────────────────────────────────────────────────────
# Пояснения: тема исходящего письма
# ─────────────────────────────────────────────────────────────
#
# Этот файл определяет ТЕМУ (Subject) исходящего письма
# по именам вложений.
#
# Формат строки:
#   ТЕМА : расширения или prefix:имя
#
# Примеры:
#   ПОДТВЕРЖДЕНИЕ : .tv .tvd prefix:ptdtv
#   СЛУЖЕБНОЕ : prefix:sluj
#   ШТ : *
#
# ─────────────────────────────────────────────────────────────
# Расширения
# ─────────────────────────────────────────────────────────────
#
# .tv .tvd — файлы с такими расширениями → тема ПОДТВЕРЖДЕНИЕ
#
# ─────────────────────────────────────────────────────────────
# Префикс имени (prefix:xxx)
# ─────────────────────────────────────────────────────────────
#
# prefix:ptdtv — имена файлов, начинающиеся с ptdtv или PDTV
# prefix:pdtv — имена файлов, начинающиеся с pdtv или ПДТВ
# prefix:sluj — имена файлов, начинающиеся с sluj или СЛУЖ
# Сравнение без учёта регистра (латиница и кириллица)
#
# ─────────────────────────────────────────────────────────────
# Несколько тем
# ─────────────────────────────────────────────────────────────
#
# Если в письме вложения под разные темы, они объединяются через пробел.
#
# ─────────────────────────────────────────────────────────────
# Правило * (значение по умолчанию)
# ─────────────────────────────────────────────────────────────
#
# Строка "ШТ : *" — для файлов, не подошедших под другие правила.
# Должна быть в конце.
#

Интервалы фонового режима

Интервалы фонового режима (бездействие), все значения в СЕКУНДАХ:

idle_threshold_seconds — порог бездействия.
  После этого времени без действий в меню выполняется экспорт непрочитанных
  в локальный inbox и отправка писем из outbox. По умолчанию: 300 (5 мин).

check_interval_seconds — интервал проверки.
  Как часто проверять, наступило ли время бездействия. По умолчанию: 30 сек.

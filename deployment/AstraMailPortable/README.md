# AstraMail для Astra Linux 1.6 x86_64

В терминале распакованной папки:

```sh
sh ./Verify-Package.sh
sh ./Run-AstraMail.sh
```

- [Запуск, проверка версии и обновление](tutorials/Запуск_и_обновление.md).
- [Импорт справочника](tutorials/Импорт_справочника.md).
- `contacts-import-example.csv` — образец с тремя вымышленными контактами.

Пользовательские настройки, почта и секреты в пакет не входят.
